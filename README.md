# MentorFinder

**让导师发现、论文追踪与研究方向探索更简单**

面向学生与科研兴趣探索者的一站式导师与学术信息平台

</div>

## 关于 MentorFinder

MentorFinder 致力于帮助用户更高效地发现潜在导师、了解研究方向、浏览相关论文，并持续追踪自己关心的学术动态。

我们希望减少导师信息分散、论文更新难追踪、筛选过程重复等问题，让用户能够把更多时间用于理解研究内容、比较研究方向和做出选择。

## 核心功能

### 🔎 导师与论文检索

- 支持从导师和论文两个维度进行搜索
- 可按姓名、研究方向、论文标题等信息查找内容
- 支持筛选、排序和组合关键词，帮助快速缩小范围
- 可查看导师画像、研究方向以及相关论文成果

### ⭐ 个性化关注

- 关注感兴趣的导师，建立个人导师列表
- 管理自定义的私有导师，补充平台暂未收录的信息
- 关注感兴趣的研究板块，形成个人研究兴趣范围
- 随时管理和调整自己的关注内容

### 📰 学术动态追踪

- 通过时间线查看关注导师的论文动态
- 浏览论文标题、摘要、作者、发布日期和研究分类
- 从平台快速前往论文原始页面继续阅读
- 持续了解目标导师和相关领域的最新进展

### ✨ 个性化周报

- 根据用户关注的导师与研究板块整理一周新增论文
- 提供周概览与 AI 总结，帮助快速把握研究重点
- 支持查看往期周报，方便持续回顾学术动态
- 同时提供面向所有用户的每周论文汇总

### 👤 账户与资料管理

- 支持注册、登录和密码重置
- 管理个人资料、关注列表和研究偏好
- 保存个性化关注内容与周报记录
- 为不同用户提供持续一致的使用体验

### 🛡️ 平台内容维护

- 支持导师资料核验与用户管理
- 支持导师和论文信息的维护
- 持续同步和更新导师与论文数据
- 保障平台信息的完整性与可用性

## `/se-projects` 部署

仓库根目录已提供单容器部署配置：内部 Nginx 在 `8080` 统一转发 Next.js 与 Django，并适配公开路径 `/se-projects/mentorfinder`。服务器部署、环境变量、持久化、更新和回滚步骤见 [DEPLOYMENT.md](./DEPLOYMENT.md)。生产 `.env`、密钥和 `data/` 不得提交到 Git。

## CI/CD

`.github/workflows/ci-cd.yml` 会在任意分支 push 以及指向 `main` 的 Pull Request 上运行前端测试与生产构建、后端测试和部署配置检查。只有 `main` 的 push（包括 PR 合并）且全部检查通过后，才会连接 `mfs` 更新并部署生产容器。

GitHub `production` Environment 需要配置以下 secrets：

- `MFS_SSH_HOST`
- `MFS_SSH_PORT`
- `MFS_SSH_USER`
- `MFS_SSH_PRIVATE_KEY`
- `MFS_SSH_KNOWN_HOSTS`

生产 `.env` 和持久化数据始终保留在服务器，不注入 GitHub Actions。
